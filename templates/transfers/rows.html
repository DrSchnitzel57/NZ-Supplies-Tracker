How it works

  1. The easiest way: export the current list, edit it in Excel, and import it back.
  2. {% if kind == "roster" %}People are matched by missionary ID. The original tracker’s export works as-is.{% else %}Items are matched by category, name and size. A “Remaining” (or Stock minus Out) number becomes a stock count with your reason — it never invents issues.{% endif %}
  3. Blank cells keep what’s already stored. To clear a value, use Edit on the record.
  4. Macros and formulas are never run.
