Backups

The server makes a verified backup every night and keeps 30 days of them, plus a backup before every update. Restoring a backup is done on the server by whoever installed the app — it is the exact way to recover from a mistake, not this page.

Backups live on the same computer as the app. Copy them somewhere else regularly in case that computer fails.
