Backups (host-local, operator-owned)

Daily host-local SQLite backups with 30-day retention run on the host (scripts/daily_backup.sh); the newest verified pre-update backup is kept until superseded. Restores are operator-run (scripts/restore.sh) under a maintenance window with integrity checks — ask the operator rather than importing a bundle for recovery. Database backups, not bundles, are the exact recovery source.

Routine spreadsheet changes belong on Missionary import / Inventory import; full history moves belong here. See docs/OPERATIONS.md for the operator runbook.

Import is atomic: bad versions, checksums, references or balances reject the whole file before anything is written. Nothing is merged with existing history.
